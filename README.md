# 🍲 چی بپزم؟ | آشپزخونه ایرانی

یک وب‌اپلیکیشن فارسی و راست‌به‌چپ برای پیدا کردن غذا بر اساس مواد اولیه موجود در خانه. طراحی ساده، رنگ‌های کرم و سبز و تصاویر خوراکی برگرفته از طرح‌های تصویری تولیدشده با AI.

## امکانات
- **۵۱ دستورپخت کاربردی** در چهار گروه غذای اصلی، سوپ، سالاد، کیک و دسر.
- **۳۷ ماده اولیه قابل انتخاب**؛ شامل همه مواد درخواستی و ۴ ماده مکمل اختیاری.
- رتبه‌بندی غذاها بر اساس **تعداد مواد اولیه مفقود** و درصد مواد موجود؛ پیشنهادها از بانک دستورهای داخلی به‌دست می‌آیند، نه مدل هوش مصنوعی آنلاین.
- جست‌وجو در نام غذا و مواد اولیه و فیلتر چهار دسته.
- دستور پخت مرحله‌به‌مرحله و تنظیم تعداد نفرات و مقدار مواد.
- علاقه‌مندی‌ها و فهرست خرید مواد مفقود (امکان افزودن دستی، تیک زدن، حذف و کپی).
- پیشنهاد تصادفی؛ ذخیره‌سازی در `localStorage` همان مرورگر.
- طراحی واکنش‌گرا برای موبایل و دسکتاپ، بدون هیچ کتابخانه یا API پولی.

## اجرای محلی

`index.html` را در یک مرورگر باز کنید. همچنین می‌توانید برای اجرای محلی با سرور ایستا از دستور زیر در پوشه پروژه استفاده کنید:

```bash
python -m http.server 8000
```

سپس `http://localhost:8000` را باز کنید. نصب `npm` لازم نیست.

## انتشار

این پروژه کاملاً استاتیک است و مستقیم روی **GitHub Pages، Netlify و Vercel** (در صورت دسترسی) قابل انتشار است. فایل `index.html` باید در ریشه و پوشه `assets/` نیز کنار آن باشد.

## فایل‌ها

- `index.html`: پوسته سایت
- `styles.css`: استایل و طراحی ریسپانسیو
- `data.js`: مواد اولیه و دستورهای پخت
- `app.js`: منطق جست‌وجو، پیشنهادها، علاقه‌مندی، جزئیات دستور، فهرست خرید
- `assets/`: تصاویر محلی بهینه‌شده WebP؛ نیاز به اینترنت ندارند
- `favicon.svg`: آیکون سایت
- `DEPLOY_GUIDE_FA.md`: مراحل آپلود و انتشار
- `PROMPTS.md`: نمونه پرامپت‌ها برای توضیح روند Vibe Coding
- `TEST_REPORT.md`: تست‌های انجام‌شده

## نکات مهم

- تمام اطلاعات فقط روی مرورگر همان دستگاه ذخیره می‌شوند، نه روی سرور؛ پاک کردن داده‌های سایت می‌تواند انتخاب‌ها را حذف کند.
- تصاویر غذا تزئینی و تولید/برش‌خورده از طرح‌های AI هستند و برای هر دستور لزوماً عکس دقیق خوراک نهایی نیستند.
- نمک، فلفل و آب پایه در مواد اصلی قابل انتخاب محاسبه نشده‌اند؛ ممکن است پخت غذا به چاشنی‌های بیشتر نیاز داشته باشد.
- دستورها خانگی و آموزشی هستند؛ زمان‌های پخت تقریبی‌اند و برای مرغ، گوشت و ماهی باید از پخت کامل اطمینان حاصل شود.
- موتور تطبیق مواد **قاعده‌محور** است، نه اتصال به API هوش مصنوعی.
